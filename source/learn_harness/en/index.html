The Core Pattern

DeepSeek Harness uses an everything-is-a-plugin architecture powered by Cordis. Every part, including the model adapter and agent loop, is a replaceable plugin.

System Architecture

Nine layers compose into a complete agent harness. Each layer builds on the one below it.
